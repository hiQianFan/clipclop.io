# 隐私说明

<p class="intro">ClipClop 将剪贴历史保存在你的设备上。核心的捕获、保存、搜索、预览与粘贴无需云端处理；应用没有账号、云同步、遥测、广告或内容分析服务，也不会在后台打开你复制的网址。</p>

## 本地保存的数据

ClipClop 会在本地保存受支持的剪贴板内容，以及相关的来源应用信息、文件路径引用和设置。应用不会检查内容并判断它是否敏感，因此请不要把剪贴历史视为密码保险库。

文件记录引用原文件的路径，不会复制或移动原文件。文件预览默认关闭；关闭时只显示已保存的名称、路径和来源信息。开启后，只有在你明确预览某个文件时，ClipClop 才可能读取该文件以取得大小、生成缩略图或调用系统预览。原文件不会上传。

本地数据库由当前系统账户以及 FileVault、BitLocker 等磁盘加密机制保护。ClipClop 目前不额外加密应用数据库。

## 网络访问

启用自动检查更新后，ClipClop 最多每 24 小时访问一次由 Cloudflare 提供的 `clipclop.io`，用于比较版本和取得更新信息；只有在你选择更新时才会下载安装文件。

本网站的更新日志和 GitHub Star 数量来自 GitHub 的公开接口。上述请求都不包含剪贴板内容、历史记录、文件路径或来源应用信息。你可以在应用设置中关闭自动更新检查。

## 你的控制方式

你可以删除单条记录、清空全部历史，并分别设置历史的保留时间和条目数量上限；达到任一上限后，ClipClop 会自动清理记录。启用“最近使用移到顶部”后，清理时间按条目的最后使用时间计算。退出 ClipClop 会停止新的剪贴板捕获。

卸载是否同时移除数据取决于操作系统和安装方式。如需删除全部本地数据，请先退出 ClipClop，再删除 `com.clipclop.desktop` 对应的应用数据目录。

## 开源与审查

ClipClop 的代码和仓库完全公开。你可以在 [GitHub](https://github.com/hiQianFan/ClipClop) 查看实现，独立核对应用保存了什么、何时读取文件以及何时访问网络。

## 系统权限

在 macOS 上，可选的自动粘贴仅使用辅助功能权限，在你选择条目后发送粘贴快捷键。拒绝授权不会影响复制：ClipClop 仍会把所选内容放入系统剪贴板，你可以手动粘贴。

文件预览使用单独的完全磁盘访问权限。macOS 要求你手动授权并返回 ClipClop 确认后，应用才会读取原文件。你可以跳过、关闭或随时撤销这项权限；文件历史仍会显示已保存的基本信息。首次启动的快速入门只使用内置示例，不会展示你的剪贴历史。

如果未来加入遥测、云同步，或其他会处理剪贴板数据的联网功能，本说明将在相关版本发布前更新。
